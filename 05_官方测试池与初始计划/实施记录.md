# 阶段 05 实施记录：官方测试池与初始计划

**状态：已完成；执行日期：2026-11-01（北京时间）。** 本阶段只注册初始语料计划，没有执行 17 次正式仿真。

## 做了什么

1. 从目标 revision `9f20940d494a223cc950a5b98f748fb28109d458` 的干净 Git archive 读取官方 AON Timer 仿真配置、公共 DVSim 测试模板、AON Timer sequence 列表、testplan 和相关继承 sequence 源码。
2. 对直接 AON Timer 测试、CSR/memory/interrupt/TL/security/stress 模板做静态盘点，保留每个候选的 testpoint、sequence、build mode、plusargs、reseed 来源、超时和来源文件。
3. 补充影响 job 解释的输入哈希契约：`cov` sim mode、AON Timer 安全反制 testplan、TL 无完整性 testplan、AON Timer 公共 sequence，以及继承的 CIP/DV sequence 基类；候选引用的四个 native sequence 也逐一纳入哈希。
4. 生成机器可读 inventory、TSV、初始计划和 SHA256SUMS；独立校验器重算 33 个源码/配置文件和用户提供 PDF 的哈希，并核对 TSV 与 JSON 身份一致。

## 为什么这么做

测试池影响命中概率和后续序列可达性。阶段 06 必须从同一份、可审计的候选集合起步，不能把旧项目 8 个测试或 379-bin 结果直接当作新实验池。

## 怎么做

本机使用 Python 3.12.14 运行生成器，输入为从本地 OpenTitan clone 导出的目标 commit archive；生成器拒绝覆盖已有输出目录。命令为：

```powershell
python "05_官方测试池与初始计划/build_test_pool.py" `
  --source-root <目标 revision 的干净源码目录> `
  --paper <用户提供的 IM-1175.pdf> `
  --output-dir "05_官方测试池与初始计划/evidence/2026-10-31/source_9f20940d_hashcomplete"
```

独立验收命令为：

```powershell
python "05_官方测试池与初始计划/verify_stage05.py" `
  --bundle "05_官方测试池与初始计划/evidence/2026-10-31/source_9f20940d_hashcomplete" `
  --source-root <同一目标 revision 的干净源码目录> `
  --paper <用户提供的 IM-1175.pdf>
```

验收实际输出 `verification: PASS`：17 candidates、33 source files independently verified、17 planned initial runs。类别计数为 native 3、CSR 6、memory 2、TL/error 2、interrupt 1、security 1、stress 2；build mode 为 default 6、cover_reg_top 11。论文 PDF SHA-256 已核对，但论文的 numeric random seed 仍记录为未披露。

阶段 06 预注册的执行输入为 `simulation_mode=cov`、`+en_cov=1`、每个候选固定 simulation seed 42、单并发、不将失败静默重试进 corpus；官方 per-test reseed 默认值仅作为 inventory 元数据保留。
