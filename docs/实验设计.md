## 分母契约

最终覆盖率必须明确分子和分母。至少同时保存：

1. AON Timer 自有 4 个 covergroup 的分母与命中；
2. 全部官方 functional group bins 的分母与命中；
3. 每个 covergroup、instance、coverpoint/cross、bin 的静态定义；
4. excluded、illegal、weight-zero、unreachable、auto-bin 和 cross 的处理；
5. 工具报告原始 expected/covered 与项目二值并集口径。

不能把 4525、4279、某个子集或某次 merged report 混写成同一个“覆盖率”。

## 测试池契约

先盘点官方 test inventory，再分别标记：AON 专用 test、CIP/通用 test、CSR/memory/TL/error/stress test、build mode、plusargs、sequence 和 reseed。测试池不会改变已定义的 bin 数，但会改变命中概率和最终并集；改变 build mode 或覆盖配置可能改变 manifest，必须新建 schema。

## 预算和方法

作者论文设置记录为 1000 submissions、10 workers、seed 42，但在作者原始测试池、bin 清单和统计脚本未获得前，只能作为待核对目标。Random 必须记录有放回/无放回、随机库、seed 生成、任务冻结时点和失败计数；Full/UCB 需记录目标 cluster、候选序列、反馈、runtime 和异步完成顺序。
